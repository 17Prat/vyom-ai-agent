# Web Scraping & Data Extraction Skill
When user asks to scrape, extract, or read data from a specific website URL (e.g. amazon.com, blogs, news sites):

1. **URL Detection**: Extract the target web link.
2. **Data Extraction**: Scrape clean LLM-ready markdown or structured text.
3. **Synthesis**: Analyze and summarize the extracted website contents according to user instructions.
